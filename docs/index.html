tech stack

Clean architecture,
no magic

Next.js handles the frontend, Python + FastAPI owns the backend. GitHub API pulls the context. PostgreSQL stores it. Redis queues the jobs. Designed to be self-hosted with one command.

backend/services/explainer.py 
@router.post("/explain")
async def explain_repo(
    payload: ExplainRequest,
    db: AsyncSession = Depends(get_db)
):
    # 1. check cache first
    cached = await db.get_cached(payload.repo_url)
    if cached: return cached

    # 2. pull context from github
    ctx = await fetch_repo_context(
        payload.repo_url,
        files=["README.md", "pyproject.toml"],
        tree=True, commits=10
    )

    # 3. stream breakdown via SSE
    return StreamingResponse(
        stream_explanation(ctx),
        media_type="text/event-stream"
    )
how it works

Four steps from URL
to full context

No complex setup. No configuration. Just a GitHub URL and a complete technical breakdown in under 30 seconds.

STEP 01
Paste a GitHub URL
Any public repo — any language, any size, any age. No authentication needed for public repos.
STEP 02
Context extraction
Pulls README, file tree, config files, language stats, and recent commits via the GitHub REST + GraphQL APIs.
STEP 03
Structured analysis
Generates a structured breakdown — purpose, architecture, key files, dependency graph, contribution guide — streamed live.
STEP 04
Explore & share
Browse the output, ask follow-up questions, and share the permalink with your team or in a PR description.
