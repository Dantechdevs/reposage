Features

Everything you need to
grok any codebase

From high-level purpose to contribution guide — RepoSage reads the repo so you don't have to.

🧠
Architecture Summary
Understands the project's purpose, design patterns, and structure in plain English. No jargon, no assumptions.
🗂️
Key File Mapping
Identifies the 5–10 most important files and explains what each one does and why it matters.
📦
Dependency Analysis
Breaks down the tech stack — frameworks, libraries, tools — and explains how they fit together.
🤝
Contributor Onboarding
Auto-generates a friendly "how to contribute" guide based on the actual repo structure and conventions.
💬
Chat with the Repo
Ask follow-up questions. "Where is auth handled?" "What does this function do?" "How do I add a new endpoint?"
🔗
Shareable Links
Every explanation gets a unique URL. Share it in PRs, docs, or onboarding emails — it updates automatically.
Tech stack

Built with the
right tools

A clean full-stack architecture — Next.js on the front, Python + FastAPI on the back, GitHub API for context. Designed to be self-hosted in one command.

  • ⚡ Next.js 14 (App Router) Frontend
  • 🐍 Python 3.11 + FastAPI Backend
  • 🧠 Claude API (claude-sonnet) AI
  • 🐙 GitHub REST + GraphQL API Data
  • 🐘 PostgreSQL (SQLAlchemy + Alembic) Storage
  • 🔴 Redis (Celery workers) Queue
  • 🚀 Vercel + Railway Deploy

async def explain_repo(repo_url: str):
    # 1. Fetch repo context from GitHub
    context = await fetch_repo_context(
        repo_url,
        files=["README.md", "pyproject.toml"],
        include_tree=True,
        recent_commits=10
    )

    # 2. Build structured prompt
    prompt = build_explainer_prompt(context)

    # 3. Stream AI explanation via SSE
    async with anthropic.messages.stream(
        model="claude-sonnet-4-20250514",
        messages=[{"role": "user", "content": prompt}]
    ) as stream:
        async for chunk in stream.text_stream:
            yield chunk
How it works

From URL to insight
in four steps

RepoSage orchestrates GitHub data + AI into a structured, readable breakdown.

1
Paste a GitHub URL
Drop in any public GitHub repo URL — works with any language, any size. No auth needed for public repos.
2
Context extraction
RepoSage fetches the README, file tree, key config files, recent commits, and detected languages via the GitHub API.
3
Analysis & breakdown
RepoSage reads the context and generates a structured breakdown: purpose, architecture, key files, dependencies, and contribution guide. Streamed in real-time.
4
Explore & share
Browse the explanation, ask follow-up questions, and share the unique link with teammates or in your PR description.
